QA Prep Project

A Selenium / TestNG / REST Assured practice framework built layer by layer: a thread-safe Singleton driver factory, an abstract BasePage with FluentWait, Page Object Model with correct return-type chaining, TestNG parallel execution, REST Assured using the Builder pattern, a Postman/Newman API suite, and a SOLID + design-pattern mapping written up in NOTES.md. GitHub Actions runs the Selenium suite and the Postman collection on every push and pull request.
